# Roadmap C — Experience and Memory Inspector

## P10 — Branches and experience records

Outcome: Morize can preserve structured task history and alternative memory states.

Work:
- logical memory branches and snapshots;
- branch diff;
- merge proposals;
- selective apply;
- trajectory records;
- case records;
- experience records;
- lesson candidates;
- tool and workflow outcome records;
- versioned learned artifacts;
- expiry policy;
- long-horizon evaluation.

Gate:
- experience remains inspectable, attributable, versioned, and reversible at the active-projection level.

## P11 — Memory Inspector

Outcome: a human can understand and control the memory system visually.

Work:
- local inspector over the stable daemon API;
- memory browser;
- scope/type/status filters;
- temporal timeline;
- evidence and provenance inspector;
- graph view with explicit/inferred distinction;
- conflict view;
- retrieval explanation;
- review queue;
- branch and diff view;
- privacy/export/removal controls;
- keyboard navigation and accessibility.

Gate:
- users can answer why a memory exists and why it was recalled without querying the storage engine manually.
