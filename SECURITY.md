# Security Policy

Morize is currently in foundation planning and has not published a production release.

## Reporting

Use GitHub private vulnerability reporting for this repository when available. Please avoid placing sensitive report details in public issues.

## Design

Security and privacy are release gates, not optional add-ons. The canonical planning requirements are documented in:

- `docs/THREAT_MODEL.md`
- `docs/ARCHITECTURE.md`
- `docs/DONOR_AND_PROVENANCE.md`
- `docs/FOUNDER_COST_AND_COMMERCIAL_BOUNDARY.md`

Public tests use synthetic data. The trusted core must not require cloud credentials for ordinary CI.

A supported-version matrix will be added with the first release.
